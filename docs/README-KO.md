# Tide 소개

> **7일짜리 작업대.**
> 꺼내 쓸 문구도, 비워낸 생각도 여기 잠깐 머뭅니다.
> **계속 쓸 것만 핀을 꽂습니다. 나머지는 조수처럼 알아서 빠져나갑니다.**

Tide는 저장소가 아닙니다. 시간이 지나면 비워지는 것이 정상 상태입니다.

## 두 가지 기능

| | Clips | Dump |
|---|---|---|
| 무엇 | 다시 꺼내 쓸 문구 | 머리에서 비워내는 생각 |
| 넣는 법 | 클립보드에서 담기(Paste from clipboard) · 직접 입력(Write) | Dump 탭을 열면 바로 타이핑 |
| 탭하면 | 클립보드로 복사 | 펼쳐서 읽기·수정 |
| 사라지는 기준 | 마지막으로 **쓴**(복사한/수정한) 날 + 7일 | 마지막으로 **손댄** 날 + 7일 |
| 핀(Pin) | 자동 삭제 없음 | 자동 삭제 없음 |

두 기능은 화면에서 분리되어 있습니다 — Clips 탭과 Dump 탭. 섞이면 잡동사니 통이 되기 때문입니다.

## 왜 7일마다 비워지나요

자주 쓰는 문구나 아직 정리하지 않은 생각은, 만질 때마다(복사·수정·핀 해제 등) 카운트다운이 7일로 다시 시작됩니다. 그래서 실제로 계속 쓰는 것은 사라지지 않습니다. 손대지 않고 7일이 지난 것만, GitHub의 개인 저장소에 조용히 보관(archive)된 뒤 이 기기에서 지워집니다.

핀을 꽂은 항목은 이 시계 자체가 멈춥니다 — 기간과 무관하게 남습니다.
