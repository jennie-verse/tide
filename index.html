Make a Shortcut

Copy → one tap → saved automatically. Set it up once.

1 · Build the "capture" shortcut

  1. Open the Shortcuts app and tap + in the top right.
  2. Add Get Clipboard.
  3. Add URL Encode, with input set to the clipboard result.
  4. Add Text, paste the address below, then append the previous step's result to the end.
    …
  5. Add Open URLs with input set to the Text result.
  6. Save it as Add to Tide.

2 · Register a way to run it (pick one)

  • Home Screen — Share → Add to Home Screen
  • Back Tap — Settings → Accessibility → Touch → Back Tap → Double Tap → Add to Tide
  • Control Center — Settings → Control Center → add Shortcuts

Good to know

  • Very long text may be cut off by URL length limits — open the app and paste directly for those.
  • Running the Shortcut opens Tide briefly, then saves. You can switch straight back.
